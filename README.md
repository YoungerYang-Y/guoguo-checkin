# 果果家庭打卡

一家三口使用的原生微信小程序（WXML / WXSS / JavaScript），当前版本 1.11.4。ICP 备案号：湘ICP备2023008600号-2X（展示于「我的」页底部、「关于与版本」弹窗与隐私指引页底部）。包括日常打卡、家庭记账、日历与报表、家庭管理、成长（体重身高与古诗/单词复习）。

## 运行与验证

微信开发者工具导入本目录。云服务 SDK 需要按开发者工具的 npm 构建流程准备；真实微信登录需要正式 AppID 和 request 合法域名。H5 预览使用本机模式。

```sh
npm test
```

测试使用隔离的微信存储与数据库模拟，不读取、修改真实家庭数据。

## 页面入口

底部 tabBar 共 5 项，顺序固定为 **打卡 / 记账 / 我的 / 成长 / 日历**（微信上限 5 项）。

- 打卡：家长本人记录、代签确认、补卡、自定义目标。
- 记账：家庭支出，记一笔 / 明细 / 汇总（按月、按年）。
- 我的：同步状态、家庭与分享、设置与数据、关于。
- 成长：古诗与单词复习、体重身高。
- 日历：按日期查看与补卡；报表与成员对比从本页入口进入（原「报表」tab 已并入日历，报表页不再是 tab 页）。
- 数据导出入口：**我的 → 设置与数据 → 数据导出**。两种模式：**完整备份**（JSON，本机全部家庭数据，可迁移恢复）与**打卡明细**（CSV，仅有效打卡，范围为本周/本月/本年/全部）。备份含家庭码与成员信息，仅自己保管、勿外发。

## 数据与同步

- `utils/store.js` 是本地数据入口；写入后持久保存待同步键和本地修改版本。
- `utils/cloudstore.js` 串行处理同步，只上传有修改的文档。写入使用 `(family_id, doc_key, updated_at)` 条件更新；冲突后重新读取并合并，插入使用家庭文档唯一约束。
- `utils/sync-merge.js` 依据上次确认值、本机值、云端值做三方合并。打卡按成员/项目/业务日期去重；扩展记录也合并新增、修改和删除。
- 云端普通文档采用 `{__gg:2,epoch,value}` 包装，兼容读取旧裸文档。新建家庭上传本地种子；加入家庭先成功拉取，再替换本地数据。
- 清空家庭数据须管理员联网操作：先提交 `gg_reset_state` 重置代次，再清理旧文档。旧设备重连后识别代次变化，丢弃旧缓存和旧待上传操作，避免记录复活。中断的清理保留为待同步操作。
- 本版本涉及同步格式升级，家庭内各设备应使用相同的新版本；旧客户端不具备解析新包装和识别重置的能力。

## 历史统计口径

- 排期修改从次日生效；周目标修改从下周一生效。历史版本保留在相应配置的 `__history` 中，历史报表按业务日期计算。
- 自定义目标编辑与归档从该目标下一周期生效；日报、历史回看与报表读取对应日期版本。
- 自定义周/月目标逐周期判断，超额不能抵消其他周期的欠额；报告只覆盖部分周期时，按有效覆盖天数折算需求次数。
- 当期指标不把未来日期算作未完成；最长连续天数统计周期内最长的一段。
- 本次升级前未保存过的旧配置版本无法逆推出。首次修改以当前配置作为历史基线，此后的变更均保留。

## 设计系统

- 颜色、圆角、阴影、间距、字阶统一定义在 `app.wxss` 的 `page` 变量里；页面样式通过 `var(--*)` 引用，不再写裸色值。
- 字阶走 2rpx 步进：20 角标 / 22–24 辅助 / 26–28–30 正文 / 32 小标题 / 36 标题 / 44–52–56 数字展示。不出现 18/21/23/25/27/34/38/46 这类临时值。
- 圆角只有 6 档（4 细线 / 8 微圆 / 12 / 16 / 24 / 32，胶囊与圆点 999）；阴影 3 档（`--sh-1/2/3`）；间距按 8 的倍数。
- 可点区域不小于 88rpx（约 44pt），按钮、胶囊、排期行、日期翻页全部适用，**已无例外**。
- `field-input` / `field-textarea` / `field-label` / `chip` / `chip-row` / `empty-block` / `loading-block` / `btn*` 只在 `app.wxss` 定义一次，页面不得裸定义同名类（只允许 `.父级 .btn` 这类局部微调）。
- 底部固定元素（sheet / undo-bar / page）统一叠加 `env(safe-area-inset-bottom)`，避免被手势条压住。
- 交互三态：按下态给所有 `view`/`text` 上的 `bindtap` 挂 `hover-class="ui-hover"`；输入框聚焦由页面 `bindfocus/bindblur` 切 `.is-focus`（WXSS 无 `:focus`）；按钮禁用用 `.btn[disabled]`。
- 空态统一用 `.empty-block`（`.empty-mark` + `.empty-title` + 可选 `.empty-desc`），加载态用 `.loading-block`（自带转圈）。不再直接写一行灰字。
- 周排期用「一行一项 + 逐天弹层」：行高 96rpx 可整行点开，弹层里一天一行 96rpx 开关，取代原来 7 列 64rpx 小方格。

## 约定与验证边界

- 图表用 WXML/CSS，不引入第三方图表库；古诗来自内置库。
- 成员可为自己创建和管理目标；跨成员分配与管理须管理员。客户端数据层和页面均检查角色，但不能替代云端 RLS / 服务端守卫。

## 家庭加入

- 两种入口：创建人转发的邀请卡片（`inv_` token）、手动输入的家庭码（`fam_`）。两者都是创建人发出的凭证，**持有即授权，接受后直接成为 active/member，不需要二次审批**。
- 数据层由 `gg_members_guard` 触发器兜底：首成员为 active/admin，其余持凭证加入一律 active/member 且 role 不能自我提权；`invited_by` 只在邀请 token 有效时被改写成邀请人 uid 留作审计，家庭码加入留空。
- 加入时选的 `member_key`（身份）决定数据归属与代签对象，同一家庭内查重、不可重复；`role`（admin/member）是另一维度的权限，由管理员调整。
- 历史遗留的 pending 成员行仍可通过成员列表批准，用于清理旧数据；新加入流程不再产生 pending。

## 角色与权限

- 角色三层：`creator`（创建人，唯一、不可降级/移除）/ `admin`（管理员，可增删成员与改设置）/ `member`（成员）。创建人身份从 `gg_families.created_by` 派生，旧家庭无需迁移。
- 身份三层：`mama`（妈妈）/ `papa`（爸爸）/ `guoguo`（宝宝）。宝宝没有微信，只作为被代签对象，不能登录打卡。
- **代签与角色无关**：任何登录的 active 家庭成员都能代签家里任何人（爸爸可代签宝宝/妈妈），每条记录写 `operator` = 实际代签人。
- 操作日志：打卡、撤销、改名、角色变更、家庭设置、加入/退出都记入 `gg_logs`（谁/何时/对谁/做了什么），随家庭云同步，保留最近 500 条，家庭页可查看。

## 家庭记账

- `pages/ledger/ledger`：记一笔 / 明细 / 汇总三个视图，入口为底部「记账」tab。
- 分类体系：13 个一级 + 74 个二级（`utils/ledger-categories.js`），编码 `1`~`13` 与 `1-01`~`13-02`，与账本口径一致。
- 餐饮口径：`1-01`~`1-04` 为早餐/中餐/晚餐/夜宵（堂食按餐次记），`1-05` 买菜食材是在家做饭的原料，`1-06` 外卖外带为外卖打包，三者不重复记账；记账页在「一级分类」下方直接展示该类的口径提示。
- 成员维度：爸爸 / 妈妈 / 果果 / 公共。**居住类（编码 2）所有支出恒为公共支出**，前端禁用成员切换，数据层 normalize 时强制改写。
- 金额以元存储、按「分」累加汇总，规避浮点误差；单笔上限 100 万元。
- 汇总提供按成员、按分类的占比条形图，并提示「其他支出」占比超过 5%（分类体系健康度信号）。
- 数据存 `gg_ledger` 并随家庭云同步。
- 汇总支持「按月 / 按年」两种范围：按年给全年合计、按月趋势、按分类占比，并与去年同比（去年无记录时不显示百分比，避免「增长 100%」误导）。
- 金额统一千分位（`5,800.00`），明细与汇总共用同一格式；汇总行显示「金额 + 占比」两行，长分类名截断不换行。
- 状态齐全：金额校验失败在输入框下方就近提示并标红（不只用 toast）；月份到边界时箭头置灰；编辑态顶部显示「正在修改哪一条」。

## 培训费并入记账（1.11.0）

- 原「培训费」页（`gg_fees`）整页下线，数据在启动时并入 `gg_ledger`，不再写两份账。
- 迁移规则：培训费只记到月份 → 落该月 1 号；成员固定果果；分类落育儿教育（书籍购买 → 教材绘本，其余课程 → 兴趣班）；原分类名写入备注开头。
- 幂等：每条带 `src='fees:<原id>'` 标记，重复启动不会重复入账；写盘失败不写完成标记，下次启动自动重试。
- `gg_fees` 本地保留不删、不再上传云端（已从同步键移除），作为历史备份。

## 成长 Tab

- tabBar 第 4 项「成长」是学习成长的汇总落地页（`pages/growth/growth`），概览古诗/单词/待复习数字，聚合三个入口：古诗复习、单词复习（含 OCR）、体重身高。
- 培训支出已在 1.11.0 并入家庭记账，不再单列入口；按年汇总在「记账 → 汇总 · 按年」查看（育儿教育 = 分类 4）。
- 四个二级页保持不变，从落地页 `navigateTo` 进入；待复习列表点进去直达对应模块的复习 tab。
- 汇总数据取自 `utils/review.js` 与 `utils/extra.js` 的现有接口，不新造数据结构；任一模块读取失败不影响入口可用。
- 运行自动测试不代表已验证真实微信登录、云端权限、文件导出或多设备联调。提交源码不会自动部署应用卡或发布小程序。
